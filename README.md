# doggr
Tinder app for pedigree dogs

## Setup
```
raco pkg install --auto
```

## Backend
The server side logic where the process orchestrator handles the main business logic for the application on the server side.

## Testing
The client side logic where the client orchestrator handles the main business logic for the appliation on the client side.

## Testing
The codebase is tested by unittests in the folder called `tests` and the folder
structure mimics the actual folder structure in the root.
